    向きの規約

    どの境界も、それが囲むものの外側を向きます。GeoJSON の右手の法則を、あらゆる次元に広げたものです。

    • ポリゴンの外周は反時計回り、穴は時計回りです。
    • 多面体の面は、右手の法則に従って法線を立体の外側に向けます。内部に空洞があれば、法線は空洞の中を向きます。
    • 多胞体のセルも、同じように外側を向きます。

    そのため、共有された境界は隣り合う2つの要素から逆向きにたどられます。多面体の辺は2つの面から、多胞体の面は2つのセルからです。このとき点の巻き数は、立体の内部で 1、外部と空洞の中で 0 になります。

    空洞のために入れ子を1段増やす必要はありません。空洞は、逆を向いた境界です。型が検査するのは入れ子の深さだけなので、ねじれた境界や閉じていない境界も型検査を通ります。GeoJSON で閉じていないリングが通るのと同じです。
