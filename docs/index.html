HyperGeoJSON

TypeScript types that extend GeoJSON to any number of dimensions. The rings of a polygon become the faces of a polyhedron, then the cells of a polychoron, and so on: one level of nesting for each dimension.

Install

$ pnpm add -D @types/hyper-geojson@github:kamataryo/types__hyper-geojson#main

Not on npm yet, so this installs straight from GitHub. The GeoJSON types it builds on come with it.

Usage

Import what you need with import type. The package holds types only, so nothing is added to your code at run time.

Viewer

Polytopes of any dimension, drawn as their shadows. Each small view keeps two axes and drops the rest, as in a three-view drawing. The large view gives every axis an equal share. Point at a vertex to follow it through all the views, and drag to turn the object.
